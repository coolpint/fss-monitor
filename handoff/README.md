# Handoff Snapshots

이 디렉터리는 다른 기기에서 작업을 이어가야 할 때만 사용하는 Git-tracked 인계 패키지 모음이다.

- 기본 원칙: `runs/`, `pipeline_state.json`, `service_config.local.json`은 계속 로컬 전용으로 둔다.
- 예외: 사용자가 기기 이동을 명시하면, 비밀이 없는 산출물만 이 디렉터리로 복사해 GitHub에 저장한다.
- 금지: 로그인 세션, 쿠키, 비밀번호, 계정 힌트, API 키, 웹훅은 이 디렉터리에 넣지 않는다.
